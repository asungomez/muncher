# Coding

Index of conventions that apply to **every** piece of code in this repository,
whatever the subsystem: the front-end, the API, the infrastructure templates and
the scripts that build the memoria.

The subsystem indexes — [front-end](../front-end/readme.md),
[api](../api/readme.md), [infra](../infra/readme.md),
[local-development](../local-development/readme.md) — say how that part of the
project is put together. These say how code is written anywhere in it. When both
have something to say, read both.

## Index

Read the file that matches the task before starting work.

| Read | When |
| --- | --- |
| [style.md](style.md) | Writing or changing any code. |
| [language.md](language.md) | Writing any text at all — an identifier, a comment, a docstring, a string a user reads. |
| [comments.md](comments.md) | Writing a comment or a docstring. |
| [types.md](types.md) | Writing in a language that admits typing — TypeScript, or Python with annotations. |
