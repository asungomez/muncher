# Memoria

The memoria is the LaTeX academic report documenting the project. Sources live
in `memoria/src/`: `index.tex` is the entry point, `macros.tex` holds custom
commands and `sections/` holds the sections. A long section is a folder with an
`index.tex` — the heading, the introduction and the `\input`s — and one file per
subsection.

## Index

Read the file that matches the task before starting work.

| Read | When |
| --- | --- |
| [tone.md](tone.md) | Writing or editing any prose in the memoria. |
| [bibliography.md](bibliography.md) | Adding a citation or a bibliographic reference, or writing a theory section. |
| [macros.md](macros.md) | Creating or referencing a requirement or a user story. |
