# Infrastructure

Index of conventions for working on the project's cloud infrastructure, hosted
on AWS and defined in CloudFormation templates under `infra/`.

## Index

Read the file that matches the task before starting work.

| Read | When |
| --- | --- |
| [design.md](design.md) | Designing infrastructure: choosing a service, sizing a resource, adding a component. |
| [deployment-role.md](deployment-role.md) | Adding or changing a resource, since the deployment role's permissions have to keep up with it. |
| [iac.md](iac.md) | Any change to the infrastructure: adding or modifying a resource, a parameter or a template. |
